# QOI and Gaussian blur: isolated Mac candidate, 2026-10-25

The isolated Mac work was followed by target measurements after Joel released
Jarvis and the panel for testing. Both candidates preserve every output byte.
Rust QOI plus blur is selected for checked deployment: 28–32% less wall time
and 26–30% less CPU time on Jarvis, with **8–10% higher peak RSS**.

## Method

Two controlled phases use `cold-image-five-sequential-processes-v1`: dashboard
plus art creation, voice backdrop, then three RGB565 PNG/QOI conversions, each
in a fresh process. Imports, encodes and process startup count. Downloads,
publication, cache hits and subsequent comparison do not count. CPU seconds sum
child user+system time; peak RSS is the largest single child's peak, not a sum.

Each phase has three inputs (Mandelblom, Stjärnenatten and the same saved NASA
image as the earlier experiment), three repetitions and two variants, with order
rotated by image/repetition: **18 cold runs per phase, 36 in total**. Sources and
their native release binaries are frozen separately. All workers run at nice 19
on the Mac. Raw load averages are recorded; the Mac was shared with other work
and wall times vary. Slow samples are retained. These small Mac cohorts are not
a Raspberry Pi performance claim or population p95 estimate.

## QOI only

The original QOI writer runs a Python pixel loop. The candidate adds an RGB-only,
dependency-free encoder to the existing Rust library. It preserves Pillow's
header, colorspace tag, run splitting, index/delta/luma choices and encoded bytes.
Python validates dimensions/dtype and owns a bounded worst-case output buffer.

Medians of three runs per input; RSS in MiB:

| Input | Variant | Wall s | CPU s | Peak RSS MiB |
| --- | --- | ---: | ---: | ---: |
| Mandelblom | Pillow QOI | 2.409 | 2.331 | 251.53 |
| Mandelblom | Rust QOI | 1.484 | 1.450 | 242.69 |
| Stjärnenatten | Pillow QOI | 2.546 | 2.507 | 249.20 |
| Stjärnenatten | Rust QOI | 1.524 | 1.495 | 243.67 |
| NASA | Pillow QOI | 2.043 | 1.997 | 249.50 |
| NASA | Rust QOI | 1.486 | 1.373 | 257.45 |

Whole-pipeline median wall time falls **27–40%**, and CPU time **31–40%**, in
this Mac cohort. Peak RSS is mixed: NASA's recorded median is 3.2% higher.
Therefore this does not establish a memory improvement. All **81** source and
device-output PNG/QOI comparisons are byte-identical to the preceding renderer.

## Blur and shadows on top of Rust QOI

The second phase compares QOI-only with QOI plus Rust separable convolution.
Python keeps the original Gaussian coefficients. Rust keeps edge padding,
vertical/horizontal pass order and coefficient order. Float32 accumulators round
after every float64 multiply/add, exactly as the original NumPy operations do.
Two caller-owned buffers replace padded arrays and per-tap temporaries. The
shadow masks and compositing equations are unchanged.

| Input | Variant | Wall s | CPU s | Peak RSS MiB |
| --- | --- | ---: | ---: | ---: |
| Mandelblom | Rust QOI + NumPy blur | 1.628 | 1.529 | 243.47 |
| Mandelblom | Rust QOI + Rust blur | 1.400 | 1.355 | 237.97 |
| Stjärnenatten | Rust QOI + NumPy blur | 1.479 | 1.461 | 249.72 |
| Stjärnenatten | Rust QOI + Rust blur | 1.358 | 1.340 | 234.83 |
| NASA | Rust QOI + NumPy blur | 1.309 | 1.286 | 246.50 |
| NASA | Rust QOI + Rust blur | 1.156 | 1.137 | 244.50 |

The additional whole-pipeline wall reduction is **8–14%**, CPU **8–12%**, in
this cohort. Peak RSS medians are 0.8–6% lower but vary by run. All **81** output
comparisons in this phase are also byte-identical. Do not combine percentages
from the separate cohorts to claim an overall speedup.

## Validation and deployment preparation

- Rust fmt, locked Clippy over all targets with warnings denied, locked tests
  (**7**) and a release build pass.
- **561** free local Python/native tests pass without skips; ESPHome configuration
  validation passes without uploading firmware.
- Independent Pillow byte/decoder tests cover runs at 62-pixel boundaries,
  one-pixel images, channel wrap, indices/collisions, gradients and random RGB.
- Independent NumPy blur comparisons match exactly for float32 and float64,
  edges, 1-pixel dimensions, kernels larger than the image, strides and unaligned
  input. Full background pixel regressions also pass.
- Native preparation stages include the new codec/blur tests for the eventual
  Jarvis build. Deployment installs library and binding before dependent Python
  image workers. A simulated deployment tests ordering and proves a failed native
  candidate starts no live copies; this simulation contacts no host.

The first isolated full test run failed two tests because the checkout lacked
the ignored LVGL simulator dependency. The existing Mac library and headers
were copied into this working copy, with the library hash checked before/after
copying. The full unchanged suite then passed. The failed log and dependency
hash are retained; no skip or gate relaxation was added.

## Jarvis target measurements

The same cold-process protocol compares baseline, QOI-only and QOI-plus-blur
in one interleaved matrix: three images, three repetitions, rotated variant order,
27 runs and 135 measured child processes. All 162 PNG/QOI file comparisons are
byte-identical, including decoded pixels. No samples are discarded. Temperature,
throttle state and load are retained per run; throttling aborts the matrix.

| Input | Variant | Wall s | CPU s | Peak RSS MiB |
| --- | --- | ---: | ---: | ---: |
| almond | baseline | 10.659 | 11.536 | 168.72 |
| almond | qoi | 8.364 | 9.275 | 168.73 |
| almond | combined | 7.328 | 8.238 | 181.92 |
| starry | baseline | 11.628 | 12.532 | 168.72 |
| starry | qoi | 8.933 | 9.842 | 168.72 |
| starry | combined | 7.918 | 8.826 | 181.92 |
| nasa | baseline | 10.102 | 11.011 | 168.69 |
| nasa | qoi | 8.278 | 9.177 | 168.69 |
| nasa | combined | 7.245 | 8.157 | 186.34 |

QOI alone cuts whole-pipeline wall time 18–23%, with effectively unchanged
peak memory. Blur then cuts another 11–12% of QOI-only time, but raises the
largest child's peak by 13–18 MiB (8–10%). It is a CPU/time optimization, not
a memory win. That trade is modest on this Pi and no image quality is lost.

All three native variants pass fmt, locked Clippy with warnings denied, locked
tests and release build on Jarvis. The combined target also passes independent
sampling, QOI, NumPy blur and complete renderer pixel tests.
